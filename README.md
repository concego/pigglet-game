# Porquinho / Pigglet 🐷🎲

Um jogo de dados clássico (Pig Game) focado em **Inclusão Digital**, desenvolvido para o projeto **Eu Concego Jogar**.

[**Jogue Agora / Play Now**](https://concego.github.io/pigglet-game/)

## 🇧🇷 Sobre o Projeto
O **Porquinho** é um jogo web bilingue criado com foco total na experiência de usuários cegos ou com baixa visão, utilizando leitores de tela como NVDA e TalkBack. 

### Diferenciais:
- **Semântica Acessível:** Estrutura HTML pensada para navegação lógica e fluida.
- **Feedback por Voz:** Uso de `aria-live` para anunciar resultados de dados e mudanças de estado automaticamente.
- **Sons Elaborados:** Áudios gerados via Python para dar feedback auditivo rico (rolagem, pulo de sucesso e trompete de derrota).
- **Inclusão Real:** Um visual de fazenda atraente para quem enxerga e uma lógica rigorosa para quem não enxerga, permitindo que todos joguem juntos.

## 🇺🇸 About the Project
**Pigglet** is a bilingual web game built with a focus on **Digital Inclusion**, designed for the **Eu Concego Jogar** initiative.

### Key Features:
- **Accessible Semantics:** HTML structure designed for logical navigation.
- **Voice Feedback:** Implemented `aria-live` to automatically announce dice rolls and game states.
- **Elaborate Sounds:** Audio generated via Python providing rich auditory feedback.
- **True Inclusion:** A charming farm-themed visual for sighted players and a rigorous logic for blind players, enabling everyone to play together.

## 🛠️ Tecnologias / Tech
- HTML5 / CSS3 (SVG Animations)
- Vanilla JavaScript
- Python (Audio Synthesis)
